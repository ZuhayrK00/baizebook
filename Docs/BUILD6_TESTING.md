# BaizeBook 1.0 (6) — What to Test

This build updates Help and support to the new website address after the GitHub repository was renamed to `baizebook`. Scoring and local storage behavior are unchanged from build 5.

1. Open Settings → Help and support. Confirm the BaizeBook help page opens successfully.
2. Open Privacy on that page and confirm the policy loads.
3. Open a support issue from the help page and confirm it points to the `baizebook` repository.
4. Confirm existing players and match history remain available after updating from build 5.

Both phone and embedded Watch use version 1.0, build 6. No account, backend or new data collection has been introduced.
